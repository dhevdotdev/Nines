# 03 — Explain Detail-screen metrics

**What to build:** Give users concise, plain-language explanations for the derived metrics they encounter on a Habit’s Detail screen.

**Blocked by:** None — can start immediately.

**Status:** wontfix

- [ ] Score, Streak, Gap, Momentum, Target progress, frequency progress, and relevant Detail indicators expose a consistent guidance affordance.
- [ ] Activating a guidance affordance opens a compact M3 Expressive explanation surface without changing the metric or its derived value.
- [ ] Explanations describe user meaning in plain language; EWMA/decay implementation jargon is not the default.
- [ ] Guidance remains readable with dynamic color, font scaling, and reduced motion.
- [ ] Compose semantics coverage verifies labels, actions, and the explanation content for representative Boolean and numerical Habits.

## Comments

The repeated metric-info-button interaction was rejected during visual review. Keep this issue as history; any future metric education should begin with a new design exploration.
