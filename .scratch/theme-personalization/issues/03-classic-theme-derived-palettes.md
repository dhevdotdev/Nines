# 03 — Classic-theme-derived palettes

**What to build:** Extend Appearance with a compact, clearly separated group
of recognizable classic-theme-derived palette sources.

**Blocked by:** 01, 02 — foundation and picker.

**Status:** done

- [ ] Catppuccin, Tokyo Night, Dracula, and Nord are persisted color sources
  with canonical, documented accent seeds.
- [ ] The picker groups these choices separately from Nines-owned palettes and
  accurately labels them as inspired rather than literal theme ports.
- [ ] Every new source has the same actual-scheme preview, selection semantics,
  immediate root-theme application, and persistence behavior as existing
  sources.

## Comments

Implemented as a deliberately small classic-theme group: Catppuccin, Tokyo
Night, Dracula, and Nord. Research records their canonical seed sources and
the non-port boundary.
