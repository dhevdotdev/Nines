# JVM coverage baseline

Run:

```sh
./gradlew :app:jacocoDebugUnitTestReport
```

Reports are written under `app/build/reports/jacoco/jacocoDebugUnitTestReport/`.

The baseline captured on 2026-08-16 is 548 of 3,738 lines (14.7%) and 150 of 1,381 branches (10.9%), generated by the pinned AGP 9.3.1 Kotlin output layout. It is a diagnostic baseline, not a quality threshold. It should rise as high-value domain, repository, ViewModel, and gesture contracts are added; it is not meaningful to compare it directly with connected Android or Compose coverage.

The report excludes generated Room/KSP/build output (including nested `*_Impl` and `*_Factory` classes), Android `R`/manifest/build-config classes, and JDK internals. The class directory is an AGP 9.3.1 implementation path and must be checked when the Android Gradle Plugin changes. The JVM report does not measure Android framework execution, Compose rendering, or Room's Android SQLite behavior. Those boundaries have separate Compose semantics, device smoke, and Room instrumentation tests.

Next coverage targets are detail analytics and gesture policy, followed by additional repository/ViewModel cases identified by future behavior changes.
