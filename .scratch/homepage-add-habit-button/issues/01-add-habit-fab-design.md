## Agent Brief

**Category:** enhancement
**Summary:** Make the homepage Add Habit control feel like a compact, expressive Nines creation
action while preserving its behavior and placement.

**Current behavior:**
The homepage uses a pinned medium, plus-only Material FAB with its default color/shape treatment.
It is technically a Material Expressive component but visually reads as generic chrome beside the
tonal, shape-rich, illustrated Habit cards.

**Desired behavior:**
Render the existing Add Habit action as a pinned, compact extended control: plus icon plus “Add
habit” label, a Cookie9-sided idle shape, and the active theme’s tertiary-container color role
paired with on-tertiary-container content. It should have a quick local spatial press response and
haptic feedback, then open the existing editor exactly as it does today. Do not animate the control
into the sheet.

**Key interfaces:**

- Homepage creation action — retains the existing action callback and bottom-end scaffold slot.
- Theme color and shape roles — derive the control from the current Material color scheme and
  expressive shape system so wallpaper and curated palettes stay truthful.
- Motion and haptics — use the project’s expressive spatial token for local geometry and existing
  haptic conventions; honor reduced-motion behavior if already provided by the system/component.

**Acceptance criteria:**

- [ ] The action remains pinned at the homepage bottom end while the Habit list scrolls.
- [ ] It visibly presents a plus icon and “Add habit” label in a compact extended layout.
- [ ] Idle shape is Cookie9-sided; colors use tertiary-container/on-tertiary-container and remain
      legible in light/dark wallpaper and curated color schemes.
- [ ] Press feedback is local, fast, expressive spatial motion plus haptic feedback; there is no
      zoom, squeeze, or hero transition into the editor.
- [ ] Tapping still opens the same Add Habit editor and creates a Habit exactly as before.
- [ ] Verify visual hierarchy, accessibility label, scrolling placement, dynamic color, and motion
      on a connected device.

**Out of scope:**

- Changing the Add Habit editor, creation/persistence flow, navigation, or the detail-screen
  numeric-entry action.
- A second homepage creation action, FAB menu, filters, or categories.
