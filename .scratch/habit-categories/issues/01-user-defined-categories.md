# User-defined categories/grouping for habits

Status: needs-triage

Group habits into categories, but user-defined ones — not a fixed preset like "morning"/"evening". E.g. a user might want a "mental health" category and tag relevant habits with it. Idea is loosely formed; not yet clear how far this should go.

No design decided yet: whether a habit belongs to one category or several, where categories show up (the main list grouped/sectioned by category? a filter, tying into the separate filters idea in `.scratch/filters/`? both?), how category management works (create/rename/delete, assign per habit), and whether this is worth the complexity at the app's current size versus something to revisit once the habit count actually grows.
